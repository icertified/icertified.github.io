# iCertified

A free certification learning and exam-preparation platform: syllabus, study notes, flashcards, chapter-wise tests and full mock exams in one place.

**Live site:** https://icertified.github.io/

Certifications available:
- **ISTQB Certified Tester Foundation Level (CTFL) v4.0**
- **ISTQB Certified Tester - Testing with Generative AI (CT-GenAI) v1.1**

- Original practice questions, chapter tests and mock exams built to each exam's official blueprint
- Flashcards for every chapter and for the whole certification, glossary and exam guide
- Resume where you left off. No sign-up: progress is stored in your own browser only.

Created by Iftikhar Haider. Independent study tool, not affiliated with ISTQB. ISTQB is a registered trademark of the International Software Testing Qualifications Board.
